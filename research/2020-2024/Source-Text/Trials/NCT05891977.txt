NCT05891977 — Effect of Tomato Paste Consumption on the Microbiota-gut-brain Axis in Healthy Adults
Source: https://clinicaltrials.gov/study/NCT05891977
Provider: ClinicalTrials.gov API v2, native foodexperiment.registry query
Retrieved: 2026-11-15 UTC
Coverage: Selected public registration fields with report lineage.

First public posting: 2023-06-07. Last posting: 2025-06-25.
Status: Completed. Tabulated registry results at retrieval: No.
Study type: Interventional. Conditions: microbiota, cognitive function and healthy lifestyle.
Sponsor: University of Barcelona. Actual enrollment: 47.
Comparison: Tomato paste or control in a randomized crossover.
Primary outcome: Change in brain-derived neurotrophic factor after both interventions.
Separate secondary outcomes: Changes in executive function, attention and memory after each intervention. The executive outcome is the Wisconsin Card Sorting Test after each three-month period.
Published report: PMID 42193265, PMCID PMC13203555, DOI 10.3390/antiox15050644.
