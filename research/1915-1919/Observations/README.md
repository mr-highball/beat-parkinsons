# Observations for 1915-1919

## Major observations

- Tretiakoff’s thesis connected nigral cellular changes and inclusion bodies with Parkinson’s pathology. An independent set of encephalitis observations provided a route for studying a secondary parkinsonian syndrome. [Mechanisms](../Mechanisms-and-Models.md) · [Clinical sources](../Clinical-and-Diagnosis.md)

## Minor observations

- The Wellcome scan records the 1918 encephalitis monograph. The date marks the book and differs from the initial 1917 description. [Clinical sources](../Clinical-and-Diagnosis.md)

## Comparison with 1910–1914

- Lewy had described inclusions in other regions. Tretiakoff identified similar inclusions and neuronal loss in the substantia nigra, reinforcing Brissaud’s earlier anatomical hypothesis with postmortem observations. [Prior observations](../../1910-1914/Observations/README.md)
