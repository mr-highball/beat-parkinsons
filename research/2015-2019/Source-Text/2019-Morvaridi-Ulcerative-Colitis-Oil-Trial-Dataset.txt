Title: The Effects of Extra Virgin Olive Oil and Canola Oil on Inflammatory Markers and Gastrointestinal Symptoms in Patients with Ulcerative Colitis

Checked: 2026-11-24
Review depth: Original deposit landing page and public file manifest. Participant data and statistical code were not inspected.

The investigators' public deposit contains a 34,352-byte SPSS data file. It is a data access trail for the same ulcerative-colitis crossover reported in PMID 31901082 (IRCT20170730035381N1). It is not an independent clinical comparison and provides no published between-oil constipation estimate in the landing page or manifest.

For Round 1 claim 0072, a future analysis would need the data dictionary and sequence, period and outcome variables to reproduce a within-person EVOO-versus-canola contrast. The original Figure 2 caption later verified a paired association favoring EVOO over canola on GSRS constipation (p<.001). The exact effect size and period or carryover analysis remain open. See research/2020-2024/Source-Text/2020-PMID31901082-Morvaridi-EVOO-vs-Canola-UC-Constipation.txt. No participant-level file is included in this catalog.
