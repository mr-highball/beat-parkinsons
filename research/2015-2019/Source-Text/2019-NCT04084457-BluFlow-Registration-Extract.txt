2019-09-10 — NCT04084457 BluFlow registration
Source: https://clinicaltrials.gov/study/NCT04084457 ; official API https://clinicaltrials.gov/api/v2/studies/NCT04084457 (downloaded NCT04084457.json, 2026-11-16). First submitted 2019-09-02, first posted 2019-09-10; last update posted 2021-07-12. Sponsor King's College London; status completed; 53 actual enrollment in current registry. Randomized parallel double-masked study in healthy 65–80 year olds. Wild blueberry powder and placebo over 12 weeks. Primary outcomes are brachial flow-mediated dilation and cognitive function, with auditory verbal learning, Corsi blocks, switching, serial 3s/7s and PANAS in the cognitive battery. Secondary mood is PANAS, BP, cerebral blood flow, and microbiome. The API states hasResults=false. This is the same trial reported by Wood 2023, not an independent study. Registry actual enrollment 53 does not match publication participant totals; no resolution inferred. Initial submission/posting date is not the start of the 2023 paper; original history shows changes to outcomes in 2021, so current outcome labels should not be assumed all prespecified in 2019 without historical comparison.
