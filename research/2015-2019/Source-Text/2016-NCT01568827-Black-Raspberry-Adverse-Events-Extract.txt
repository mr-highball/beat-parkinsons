Official results adverse event module collapsed across exposures
ClinicalTrials.gov first posted results March 15, 2016 for NCT01568827. The two randomized sequences each contain five participants. The record lists zero serious and zero other adverse events in each sequence over one month. Each sequence includes berry slurry and water, so the count does not isolate an exposure. A valid estimate for orthostatic lightheadedness was not reported.
