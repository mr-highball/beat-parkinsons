STUDY GROUPS AND INTERVENTIONS

Arm groups
  -
    Label: DBS-Expert Programming First
    Type: EXPERIMENTAL
    Description
      These patients will be undergo algorithm based programming using Kinesia-based assessment
      (DBS-Expert) first and then be programmed by a clinician within five days.
    Intervention names
      - Device: Algorithm based programming using Kinesia-based assessment
  -
    Label: Traditional Programming First
    Type: EXPERIMENTAL
    Description
      These patients will be programmed by a clinician first and then undergo algorithm based
      programming using Kinesia-based assessment (DBS-Expert) within five days.
    Intervention names
      - Device: Algorithm based programming using Kinesia-based assessment
Interventions
  -
    Type: DEVICE
    Name: Algorithm based programming using Kinesia-based assessment
    Description
      DBS-Expert includes a tablet-based software application (app) for guiding DBS programming
      and a Kinesia motion sensor unit for automated motor assessment. Algorithms search the
      programming parameter space to resolve an optimal set of programming parameters.
    Arm group labels
      - DBS-Expert Programming First
      - Traditional Programming First
    Other names
      - DBS-Expert

REGISTERED OUTCOME MEASURES

Primary outcomes
  -
    Measure: Programming time when programmed using Kinesia-based assessment (DBS-Expert) compared to programming time when programmed by a clinician
    Description
      Amount of time it took to arrive at DBS settings that provide sufficient therapeutic
      benefit will be compared across programming sessions
    Time frame: Up to 2 hours (from start of programming session until end of programming session)

ELIGIBILITY

Eligibility criteria
  Inclusion Criteria:

    -  The ability to provide informed consent

    -  Clinical diagnosis of idiopathic Parkinson's disease (PD)

    -  Implanted deep brain stimulation (DBS) system for tremor and/or bradykinesia

  Exclusion Criteria:

    -  Significant medical or psychiatric illness or dementia as evidenced by a score less
       than 26 on the Montreal Cognitive Assessment

    -  Not capable of functioning independently

    -  Individuals so symptomatic as to compromise safety
