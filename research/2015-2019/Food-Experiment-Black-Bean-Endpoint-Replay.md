# Kidney beans in a Parkinson motor task

## Raw kidney beans as objects in a Parkinson spoon task

This Parkinson motor-learning trial first posted November 9, 2015. The task is moving two raw kidney beans with a spoon between set points with the non-dominant hand. These beans are task objects. The arm does not specify black beans as food or track postural instability. No summary results were posted in the retrieved registry snapshot. [Official registry](https://clinicaltrials.gov/study/NCT02600858)
