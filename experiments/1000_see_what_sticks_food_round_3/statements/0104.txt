ID: 0104
Category: food
Ingredient: cashew
Preparation: roasted
Symptom: executive function impairment
Direction: reduces
Statement: Consuming roasted cashew reduces executive function impairment in people with Parkinson's disease.
Verdict: Unknown
Confidence: 50
Rationale: Unknown (Researched): no controlled human trial isolates roasted cashew nuts for executive function impairment; the only human crossover containing cashews bundled 4 nuts (walnut, pistachio, cashew, hazelnut; Nijssen 2023, n=28) and reported null executive function and psychomotor speed despite memory gains, Theodore 2021 found no isolated cashew cognitive RCT, and rodent memory assays (Desire 2023, Medeiros-Linard 2018) did not measure executive function impairment.
