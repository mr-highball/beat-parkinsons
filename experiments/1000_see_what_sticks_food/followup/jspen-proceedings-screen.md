## Replay

Save the original PDF files using the inventory's `meeting` field, e.g. `jspen-30-384.pdf`. For archived sources, use the exact recorded URL, including its language suffix. The PyMuPDF CLI extracts text with a form feed after each physical page. The native Free Pascal reader checks original file length, SHA-256, extracted page count and the frozen statement hash. Contextual review inspects the named report within each flagged page. The native audit checks the exact review keys.

```powershell
$experiment = 'experiments/1000_see_what_sticks_food'
$followup = "$experiment/followup"
$capture = "$experiment/build/jspen-discovery/2015"
$bin = "$experiment/build/followup-3.3.1-i386-win32/bin"
$inventory = "$followup/jspen-2015-issue-inventory.tsv"
Import-Csv $inventory -Delimiter "`t" | ForEach-Object {
    $stem = "$capture/jspen-$($_.meeting)"
    python -m pymupdf gettext -mode simple -output "$stem.formfeed" "$stem.pdf"
    if ($LASTEXITCODE) { throw "Text extraction failed for $stem" }
}
& "$bin/foodexperiment.jsdr.exe" $inventory "$followup/jsdr-topic-vocabulary.tsv" $capture $experiment "$followup/jsdr-claim-vocabulary.tsv" JSPEN
if ($LASTEXITCODE) { throw "JSPEN page screen failed" }
& "$bin/foodexperiment.crossref.exe" audit-topics "$followup/jspen-2015-issue-review-keys.tsv" "$capture/context-audit.tsv" "$followup/jspen-2015-issue-reviews.tsv"
if ($LASTEXITCODE) { throw "JSPEN contextual audit failed" }
```
