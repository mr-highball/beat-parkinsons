# Earlier olive oil and rosemary source holds

The original 2016 ANA program PDF contains 265 pages. Abstract S265 on printed page S101 describes an isolated olive-oil constituent in a rat cerebral ischemia study. Abstract S186 on S68 and S338 on S131 discuss rest tremor in separate contexts. The publisher file supplies complete conference-abstract coverage and does not report an extra-virgin olive-oil Parkinson rest-tremor result. [Original proceedings PDF](https://onlinelibrary.wiley.com/doi/pdfdirect/10.1002/ana.24759)
