# Whole-kiwi human trial source decisions

Three previously provisional kiwi-attention records reached full-text review. The current stable screen now has 103 source-specific rows, with 89 excluded, 12 related and two pending. The other 1,491 retrieved kiwi records retain provisional status. The source reviews use stable work IDs and retain exposure context. Their measured outcomes supply no direction for the Parkinson attention hypothesis.
