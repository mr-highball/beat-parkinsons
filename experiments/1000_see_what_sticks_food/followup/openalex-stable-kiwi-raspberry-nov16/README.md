## Native commands

- `foodexperiment.openalex sorted QUERY_TSV OUTPUT_DIR` starts a fresh sorted capture of the exact plan.
- `foodexperiment.openalex resume-sorted QUERY_TSV PRIOR_DIR OUTPUT_DIR` validates and resumes that method into a new directory. Complete routes reuse the earlier capture.
- `foodexperiment.openalex verify-sorted QUERY_TSV CAPTURE_DIR` validates sorted pages and receipts offline.

Sorted receipts add the exact request method. The tool verifies the provider's echoed sort and increasing work IDs across page boundaries. The original commands still use their existing headers and validation. Sorted mode uses the provider offset range and comparison boundary. The provider's 10,000-result offset ceiling still requires a cursor route for larger queries.
