# PubMed Boolean query conversion audit

The original adapter searched for the first literal `) AND (` separator. It replaced everything before it with a fixed Parkinson disease block. This discarded an ingredient when the ingredient was first, replaced explicitly named populations such as Lewy body disease, and rejected some otherwise valid ungrouped operands. The automatic MeSH addition also went after the entire retained expression, so a MeSH match could satisfy a compound expression without matching the endpoint.

The converter now preserves Boolean operands, explicit search tags, nesting and quoted text. It keeps the historical Parkinson expansion for the generated disease-first shape. Automatic MeSH is limited to an unambiguous single exposure group with only title/abstract leaves joined by OR. A focused expression can specify a MeSH leaf inside its intended group. The provider’s own translation and warnings remain part of each receipt.

## Verification

- Native FPC 3.3.1, i386 Win32, with assertions, range, overflow and I/O checks. The PubMed build runs the new regression executable. Fixtures cover the canonical expansion, exposure-first searches, nested conjunctions with a registered MeSH ID, explicit MeSH, quoted delimiters, malformed queries and UTF-8 text. [Build command](../tools/build-pubmed.ps1) · [Regression fixtures](../tools/foodexperiment.pubmedquery.tests.lpr)
- A native comparison against the 169 original ingredient-search receipts reproduced all submitted strings exactly. Live canonical PR001 and PE081 also reproduced the original counts, one and 343. A separate live PE081 with a compound coffee/caffeine and wearing-off endpoint submitted both groups with the endpoint intact and retrieved two records.
- The November 15, 2026 UTC replay includes 33 complete requests, including the two canonical controls and the registered-MeSH endpoint regression. The receipt preserves both the submitted query and the provider’s interpretation. A completed retrieval with a warning confirms receipt and pagination. It may still have provider-side alias omissions. [Live verification receipts](pubmed-converter-replay.tsv)
