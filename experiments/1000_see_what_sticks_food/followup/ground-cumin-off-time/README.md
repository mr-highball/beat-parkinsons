# Search record for statement 0064

Frozen claim: Consuming ground cumin reduces daily off time in people with Parkinson's disease.

Verdict after this pass: Unknown. One original Parkinson case documented oral use of a true cumin-containing multi-ingredient tablet and an OFF item, a first bridge in this review. The ground preparation was unspecified, the ordinal item stayed at 2, and attribution to cumin or a change in hours/day was not possible.

- The public Rāsnādi Kvātha Cūrṇa (Mahā) monograph from PCIM&H, indexed as a draft based on AFI Part I 4:28, lists Dhanyaka/Coriandrum sativum. An Everest commercial Maharasnadi listing instead names Jeeraka/Cuminum cyminum. These versions do not verify the batch in CTRI/2024/07/070428, which was found in a registry mirror after the official site timed out. The mirror describes separate oral Maharasnadi and Kapikacchu comparisons plus related rectal treatment, without separate daily OFF results, in a planned sample that excludes people using Parkinson medicines. Continue to the specific supplied formulation and original investigators' results before using it.
