# Nutmeg and paprika follow-up

The November 13, 2026 UTC checkpoint covers all 14 ground or grated nutmeg statements and all 14 ground or smoked paprika statements. The searches considered improvement, worsening and inconclusive findings. No primary study verified a Parkinson symptom direction for the specified oral culinary exposure. The checkpoint adds 36 related assessments and four pending assessments across 19 claims.

## Search audit

- Native PubMed and Europe PMC each reconciled the four direct and related ingredient disease queries, with 49 distinct PubMed IDs. PubMed translation dropped several quoted regional phrases, which were followed in ranked searches. Five native Europe PMC symptom queries returned all 374 records, including 59 MED hits before deduplication. ClinicalTrials.gov returned all 2,874 broad nutmeg records with selected fields and all 79 broad paprika records. Fielded and disease registry expressions returned smaller sets, including several false hits from MACE expansion.
