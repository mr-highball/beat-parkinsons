# Europe PMC sort input and exact query recovery

The historical CLI used a dash for the optional prior-output and sort arguments. The old tool sent the sort dash as a literal provider sort value. The same query returned HTTP 200 and 14 records with sort omitted on each of two historical builds. A raw control differing only by the added sort value returned HTTP 503 with no verified hit count. The native tool now treats a dash as a placeholder for the default sort. A validation run with page size 5 retrieved the same 14 identifiers over three pages. Explicit citation sorting still worked. The exact 16 expressions for saffron, black beans, celery leaf and caraway returned every reported page with sort omitted. Their 215 appearances represent 211 distinct source keys, with 33 in saffron, 155 in black beans and 23 in the combined celery/caraway set. Each returned key has a disposition that distinguishes primary full-text checking, title or abstract context, and access limits. No directly matched dietary Parkinson outcome emerged. A separate healthy-adult primary trial verifies canned black beans with rice and measures postexercise muscle protein synthesis.
