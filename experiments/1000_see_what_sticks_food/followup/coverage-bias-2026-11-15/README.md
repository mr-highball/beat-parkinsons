Reuse query families only when the expressions cover each listed endpoint. Search full-text methods and official trial arms for the exposure when indexed titles omit it. For large generic results, intersect with unambiguous botanical or culinary terms and preserve the broad and narrowed memberships. Handle regional searches in native script with a verified fixture and log any spelling the provider drops. Read the source around both hits or verify their absence from the relevant methods and tables. ## Access and result timing
