# Scrambled egg and visual hallucinations · 0173

The Parkinson diet trial's ketogenic and low-fat menus both include a scrambled preparation. The ketogenic arm also had one visual hallucination event that resolved after pramipexole reduction. Neither individual egg intake nor a dated link between the event and a meal was reported.
