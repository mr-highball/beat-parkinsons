# Adelaide choking and potato food-identity follow-up

Reviewed November 12, 2026 for [statement 0290](../statements/0290.txt). The exposure in the frozen statement is baked potato consumed by people with Parkinson’s disease. Choking cases can identify an acute food obstruction. The claim also requires evidence that baked potato worsens swallowing difficulty, which a series selected for choking events cannot estimate.

## Additional case-report archive to screen

The Japan Council for Quality Health Care provides annual CSVs for medical incidents and published near misses. It supplied data for a 2023 hospital series of 300 food obstructions. The 2010–2025 download page lists 32 files, two per year. An August 2026 provider note identifies the corrected 2025 incident file. The web case search describes selected near misses before April 2025 and all reported near misses from April 2025. These files contain reported cases from participating institutions. [Official annual files](https://www.med-safe.jp/contents/report/report.html) · [Registry coverage](https://www.med-safe.jp/mpsearch/SearchReport.action) · [300-case study, Methods](https://www.sciencedirect.com/science/article/pii/S0300957223001193)

On November 12, 2026 the completed screen covered all 32 files and 178,949 case rows. The files totaled 314,171,230 bytes. Interrupted transfers were resumed with HTTP 206 byte ranges and completed files matched the provider’s length. A Free Pascal CSV reader decoded Windows Japanese code page 932 and inspected all fields of each case row. It located the case ID header in each export and found no malformed case rows or duplicate IDs within individual files. The accompanying table records each export’s length, provider Last-Modified and ETag, SHA-256 and query counts. Last-Modified is the server file revision, which can differ from a case’s public posting date. [Per-export coverage and metadata](jcqhc-annual-export-screen.tsv)

The screen found 271 rows with Parkinson and swallowing terms and 18 rows with tuber and swallowing terms. Zero rows combined Parkinson and tuber terms. None of the 18 tuber-and-swallowing rows matched a baked preparation term. Direct primary case pages were accessible for all 18 and were checked individually below. The expanded term set recovered 11 Parkinson-and-swallowing rows in the 2021 incident file, one more than the earlier screen of the same 5,243 rows. The known fatal Parkinson’s case A77543639251F58E0 was retrieved again and reports porridge-like residue without an ingredient identification.
