# Egg, bell pepper and cauliflower follow-up

The November 13, 2026 disease and ingredient searches covered the four egg, seven bell pepper and two cauliflower hypotheses. Europe PMC reported and returned 155 appearances across three completed queries. PubMed reported and returned 144 across three completed queries using the rebuilt UTF-8 reader. The first run used an outdated executable, which corrupted aliases and returned zero across all three queries. The rerun preserved the submitted characters, while the provider's interpreted expressions still omitted some aliases. OpenAlex returned HTTP 429 on all six registered routes. The queries remain available to replay. The disease-indexed results included egg-laying and embryology studies, gastric physiology methods, in vitro hen lysozyme studies, sulforaphane reviews and crop diseases. The Hegelmaier paper named eggs in the intervention menu. The premorbid Spanish diet survey compared recalled egg use by later Parkinson diagnosis and has no symptom or preparation outcome. The Washington State pepper study addressed Parkinson diagnosis and is already in the research catalog. Additional primary sources came from symptom-specific web searches, named investigators and linked registrations. Those routes have no enumerable search total.
